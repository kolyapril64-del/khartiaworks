# Добова доповідь ППО: генератор Excel-книги

Скрипт `generator/build_workbook.py` створює книгу Excel (.xlsx) для добової доповіді ППО по підрозділах.

## Що в книзі

| Аркуш | Призначення |
|---|---|
| **Інструкція** | як заповнювати, кольори, права доступу, як додати підрозділ |
| **Зведення** | дата звіту (єдине поле для вводу) і автоматичні таблиці: бойова робота, удари противника, сили і засоби по підрозділах |
| **Доповідь** | текст добової доповіді у встановленому форматі (по об'єднанню або по одному підрозділу); формулювання рядків і перелік типів для кожного показника редагуються на аркуші |
| **За типами цілей** | виявлено / застосовано / знищено за типами цілей; матриця «тип цілі × підрозділ» |
| **Аркуш підрозділу** (по одному на кожен) | черговий і зміна, РЛС (наявність і робота), екіпажі перехоплювачів, журнал цілей, удари противника |
| **Довідники** | списки для випадаючих меню: підрозділи, типи цілей, засоби ураження (з групою ФПВ / Стр.зб / Інші), результати тощо |
| **Розрахунок** | службовий аркуш з проміжними підрахунками |

Головний принцип: **підрозділ вставляє готовий текст доповіді** у журнал (один рядок означає одну доповідь),
а поля (час, тип цілі, район, квадрат, засіб ураження, боєприпас, екіпаж, результат, витрати) розбираються
формулами Excel за таблицями ключових слів на аркуші «Довідники». Макроси не потрібні. Розібрані поля
можна виправити вручну. Усі підсумки рахуються формулами (`COUNTIFS` / `SUM` через `INDIRECT` за кодом
аркуша з довідника) з розбивкою за групами засобів: FPV-перехоплювачі, стрілецька зброя,
зенітна артилерія, ЗРК/ПЗРК, інші.

Права доступу: аркуші захищені від випадкових змін без пароля, редагувати можна лише жовті клітинки.
Паролі для кожного підрозділу задаються в Excel (див. аркуш «Інструкція»).

## Запуск

```bash
pip install openpyxl
python generator/build_workbook.py generator/config.example.json output.xlsx
```

Конфіг:

```json
{
  "org_name": "Назва об'єднання",
  "org_emblem": "emblems/org.png",
  "units": [{"code": "П1", "name": "Підрозділ 1", "emblem": "emblems/p1.png"}],
  "radars": ["Тип РЛС 1"],
  "region_words": ["Київ"],
  "weapons": [["Вид озброєння", "Боєприпас", "ФПВ"]],
  "means_keywords": [["слово в тексті", "Вид озброєння", 1]]
}
```

- `code` — назва вкладки підрозділу (до 31 символу, без `: \ / ? * [ ]`);
- `units` — до 15 підрозділів; `emblem` / `org_emblem` — необов'язкові шеврони (PNG/JPG, шлях відносно конфігу);
- `radars` — необов'язковий список типів РЛС;
- `region_words` — початок назви області, як її пишуть у доповідях (допомагає вирізати назву населеного пункту);
- `weapons` — необов'язковий перелік засобів ураження: вид озброєння, боєприпас (може бути порожнім),
  група (`ФПВ`, `Стр.зб`, `ЗА`, `ЗРК/ПЗРК`, `Інші`). Якщо не задано, береться короткий загальний перелік;
- `means_keywords` — необов'язкові ключові слова для розпізнавання засобу: слово, вид озброєння,
  пріоритет (0 — запасне загальне слово, без числа — 1).

> ⚠️ Репозиторій публічний. Не комітьте сюди заповнені книги, конфіги з реальними назвами,
> шеврони, переліки засобів, координати, позивні чи будь-які службові дані. `.gitignore` уже виключає `*.xlsx` і `config.local*.json`.
